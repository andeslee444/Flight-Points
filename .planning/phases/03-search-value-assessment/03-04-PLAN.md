## Context

This plan adds three information-layer features to the search page: (1) metro airport deduplication toggle (JFK/EWR/LGA collapsed by default, expandable), (2) alliance gateway coverage labels ("oneworld — covers AA, BA, JAL..."), and (3) scraper health transparency notices ("Star Alliance: Limited coverage"). All data is static — no DB queries needed. Metro dedup is client-side filtering using the Zustand `search-store`.

## Must-Haves (Goal-Backward)

1. By default, results for nearby airports (JFK/EWR/LGA) are deduplicated — user sees results grouped under the metro representative (JFK)
2. A toggle allows the user to "Show all airports" and see JFK, EWR, LGA results separately
3. The search page shows alliance gateway coverage labels indicating which alliances are covered
4. The search page shows health notices for scrapers that are blocked or have limited coverage
5. Coverage notices are dismissible (or at least unobtrusive)

### components/metro-toggle.tsx

Small Client Component toggle for metro dedup. Uses the `useSearchStore` from `stores/search-store.ts`.

```typescript
'use client';

import { useSearchStore } from '@/stores/search-store';
import { Button } from '@/components/ui/button';

export function MetroToggle() {
  const { showAllAirports, setShowAllAirports } = useSearchStore();

  return (
    <Button
      variant="ghost"
      size="sm"
      onClick={() => setShowAllAirports(!showAllAirports)}
      className="text-xs text-muted-foreground hover:text-foreground"
    >
      {showAllAirports ? 'Group nearby airports' : 'Show all airports'}
    </Button>
  );
}
```

4. Add metro dedup logic inside the component:

```typescript
const { showAllAirports } = useSearchStore();

// Metro dedup: when collapsed, keep only the first (best CPP) result per metro group
const displayResults = showAllAirports ? results : (() => {
  const seen = new Set<string>();
  return results.filter((deal) => {
    const originRep = METRO_GROUPS[deal.origin] || deal.origin;
    const destRep = METRO_GROUPS[deal.destination] || deal.destination;
    const key = `${originRep}-${destRep}-${deal.cabin}-${deal.airline}-${deal.departureDate}`;
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
})();
```

### components/coverage-notices.tsx

Server-safe component (no `'use client'`) that displays alliance coverage info and scraper health warnings.

```typescript
import { Badge } from '@/components/ui/badge';
import { ALLIANCE_LABELS, SCRAPER_HEALTH_NOTICES } from '@/lib/coverage';

export function CoverageNotices() {
  return (
    <div className="space-y-3 mt-6 mb-2">
      {/* Alliance coverage labels */}
      <div className="flex flex-wrap gap-2">
        {Object.entries(ALLIANCE_LABELS).map(([key, label]) => (
          <Badge
            key={key}
            variant="outline"
            className="text-xs text-muted-foreground border-border font-normal py-1"
          >
            {label}
          </Badge>
        ))}
      </div>

      {/* Scraper health notices */}
      {SCRAPER_HEALTH_NOTICES.length > 0 && (
        <div className="space-y-1">
          {SCRAPER_HEALTH_NOTICES.map((notice, i) => (
            <div
              key={i}
              className={`text-xs px-3 py-1.5 rounded ${
                notice.severity === 'warning'
                  ? 'bg-amber-500/10 text-amber-400 border border-amber-500/20'
                  : 'bg-zinc-500/10 text-zinc-400 border border-zinc-500/20'
              }`}
            >
              {notice.message}
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

**Design:** Alliance labels as outline badges in a row (wrap on mobile). Health notices as small inline banners below, styled with warning/info colors. Not dismissible (they're small and informational).
