## Context

This plan builds the core result display component. All enrichment data is already computed by `enrichFlightResult()` — `FlightResultCard` is purely a display component that renders existing `EnrichedDeal` fields. The `SearchResults` wrapper is a Client Component that handles the metro dedup toggle from Plan 03-04 (prepared here as a passthrough).

## Must-Haves (Goal-Backward)

1. Each result shows: airline, flight number, origin/dest, departure/arrival times, duration, stops, cabin
2. Each result shows CPP value (e.g., "2.3¢/pt") prominently
3. Each result shows a deal quality badge: "Incredible" (hot), "Great" (good), "Fair" (fair) — mapped from `dealRating`
4. Each result shows cash savings: "Saves you $X vs cash" computed from `cashPrice - points_value`
5. Each result shows sweet spot tier badge (S/A/B) when matched
6. Each result shows transfer partner pills: "Amex MR", "Chase UR" etc. from `transferFrom`
7. Each result shows a "Book" link that opens the airline's award booking page in a new tab
8. Each result shows a freshness indicator: "Scraped 3 hours ago" from `scrapedAt`
9. Results are fully responsive on mobile

This is a Server-safe component (no `'use client'`). It renders an `EnrichedDeal` with all value assessment fields.

```typescript
import { Badge } from '@/components/ui/badge';
import { Card, CardContent } from '@/components/ui/card';
import { Button } from '@/components/ui/button';
import { relativeTime } from '@/lib/time';
import type { EnrichedDeal } from '@/lib/enrichment';

// Tier badge colors (same as DealCard for consistency)
const TIER_COLORS: Record<string, string> = {
  S: 'bg-amber-500 text-black font-bold',
  A: 'bg-emerald-600 text-white',
  B: 'bg-blue-600 text-white',
};

const TIER_LABELS: Record<string, string> = {
  S: 'S-Tier: Holy Grail',
  A: 'A-Tier: Excellent',
  B: 'B-Tier: Great',
};

// Deal rating badge — mapped from internal names to user-facing labels
const RATING_STYLES: Record<string, { label: string; className: string }> = {
  hot: { label: 'Incredible', className: 'bg-red-500/20 text-red-400 border-red-500/30' },
  good: { label: 'Great', className: 'bg-emerald-500/20 text-emerald-400 border-emerald-500/30' },
  fair: { label: 'Fair', className: 'bg-zinc-500/20 text-zinc-400 border-zinc-500/30' },
};

// Program slug → display name (for transfer partner pills)
const PROGRAM_DISPLAY: Record<string, string> = {
  'amex-mr': 'Amex MR',
  'chase-ur': 'Chase UR',
  'citi-typ': 'Citi TYP',
  'capital-one': 'Capital One',
  bilt: 'Bilt',
};

// Cash savings computation
function cashSavings(deal: EnrichedDeal): number | null {
  if (!deal.cpp || !deal.pointsRequired) return null;
  // estimateCashPrice is already embedded in CPP calc — reverse engineer
  // cashPrice ≈ (pointsRequired * cpp / 100) + taxes → savings = cashPrice - cost_to_you
  // But simpler: cashPrice was used to compute CPP, so:
  // cashPrice = (pointsRequired * cpp / 100) + taxes (approximately)
  // For display, compute estimated cash price and subtract taxes paid
  const estimatedCashValue = (deal.pointsRequired * deal.cpp) / 100;
  // The savings is the difference between what you'd pay in cash vs points + taxes
  const savings = Math.round(estimatedCashValue - deal.taxes);
  return savings > 0 ? savings : null;
}
```

### components/search-results.tsx

Client Component wrapper that renders the result list. Currently a simple pass-through, but structured to support metro dedup toggle (Plan 03-04 will add the toggle logic).

```typescript
'use client';

import { FlightResultCard } from './flight-result-card';
import type { EnrichedDeal } from '@/lib/enrichment';

interface SearchResultsProps {
  results: EnrichedDeal[];
  from: string;
  to: string;
}

export function SearchResults({ results, from, to }: SearchResultsProps) {
  // Metro dedup toggle will be added in Plan 03-04
  const displayResults = results;

  if (displayResults.length === 0) {
    return (
      <div className="text-center py-12 text-muted-foreground">
        <p className="text-lg">No award flights found for {from} → {to}</p>
        <p className="text-sm mt-2">
          The daemon scrapes this route periodically — try again later or adjust your search
        </p>
      </div>
    );
  }

  return (
    <div className="space-y-4">
      {displayResults.map((deal) => (
        <FlightResultCard key={deal.id} deal={deal} />
      ))}
    </div>
  );
}
```
