## Context

This plan creates the search form UI and the search results page. The data layer (`lib/search.ts`) and shadcn components are already available from Plan 03-01. The search form is a Client Component with airport autocomplete (shadcn Popover + Command), cabin selector, date picker, and program selector. The search page is an RSC that reads `searchParams`, queries the DB directly via `getSearchResults()`, and passes results to client components.

## Must-Haves (Goal-Backward)

1. User can type an origin and destination airport and see autocomplete suggestions filtered from `AIRPORT_LIST`
2. User can select cabin class (economy/business/first/any) and a date
3. User can select a credit card program perspective (same 5 as Phase 2 filter bar)
4. Submitting the form navigates to `/search?from=JFK&to=NRT&class=business&program=amex-mr&date=2026-04-01`
5. The search page reads `searchParams`, queries `getSearchResults()`, and renders results
6. The page is fully responsive (form stacks vertically on mobile)
7. A nav header appears on all pages with links to Deal Feed and Search

- Desktop (md+): single row with all inputs side by side: `grid grid-cols-2 md:grid-cols-6 gap-3`

**Airport Combobox pattern:**
Each combobox is a Popover wrapping a Command. The CommandInput filters `AIRPORT_LIST` client-side by matching the search string against `code` or `city` (case-insensitive). Each CommandItem displays `"JFK — New York JFK"` format. On select, update state with the IATA code and close the popover. The popover trigger button shows the selected airport code or placeholder text.

**CRITICAL: Do NOT use `useSearchParams()` in this component.** The initial values come from props passed by the RSC page. This avoids the Suspense boundary requirement.

### app/search/page.tsx

RSC page that awaits `searchParams` (Promise in Next.js 16), queries DB directly, and renders.

```typescript
import { Suspense } from 'react';
import { getSearchResults } from '@/lib/search';
import { SearchForm } from '@/components/search-form';
// SearchResults and FlightResultCard come from Plan 03-03.
// For now, render results as a simple JSON dump or placeholder list.

export const dynamic = 'force-dynamic';

export default async function SearchPage({
  searchParams,
}: {
  searchParams: Promise<{
    from?: string;
    to?: string;
    class?: string;
    program?: string;
    date?: string;
  }>;
}) {
  const params = await searchParams;
  const { from, to, class: cabin = 'business', program = 'amex-mr', date } = params;

  const hasSearch = Boolean(from && to);
  const results = hasSearch
    ? await getSearchResults({ from: from!, to: to!, cabin, program, date })
    : [];

  return (
    <main className="container mx-auto px-4 py-8">
      <h1 className="text-3xl font-bold mb-2">Search Award Flights</h1>
      <p className="text-muted-foreground mb-6">
        Find the best points redemptions across all programs
      </p>

      <SearchForm initialValues={params} />

      {hasSearch && (
        <div className="mt-8">
          <div className="flex items-center justify-between mb-4">
            <h2 className="text-xl font-semibold">
              {results.length} result{results.length !== 1 ? 's' : ''} for {from} → {to}
            </h2>
          </div>
          {results.length === 0 ? (
            <div className="text-center py-12 text-muted-foreground">
              <p className="text-lg">No award flights found</p>
              <p className="text-sm mt-2">
                The daemon scrapes this route periodically — try again later or adjust your search
              </p>
            </div>
          ) : (
            <div className="space-y-4">
              {/* Placeholder: Plan 03-03 will replace this with FlightResultCard */}
              {results.map((deal) => (
                <div key={deal.id} className="p-4 border border-border rounded-lg">
                  <div className="flex justify-between">
                    <span className="font-medium">{deal.airline} {deal.flightNumber}</span>
                    <span className="text-primary font-bold">{deal.pointsRequired.toLocaleString()} pts</span>
                  </div>
                  <div className="text-sm text-muted-foreground mt-1">
                    {deal.origin} → {deal.destination} · {deal.cabinDisplay} · {deal.departureDate}
                    {deal.cpp != null && ` · ${deal.cpp}¢/pt`}
                  </div>
                </div>
              ))}
            </div>
          )}
        </div>
      )}

      {!hasSearch && (
        <div className="text-center py-16 text-muted-foreground">
          <p className="text-lg">Enter an origin and destination to search</p>
        </div>
      )}
    </main>
  );
}
```

**CRITICAL:** `const params = await searchParams` — must await because searchParams is a Promise in Next.js 16.
