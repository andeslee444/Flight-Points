## Context

This plan adds transfer bonus awareness to the deal display. When a credit card program has an active transfer bonus to an airline (e.g., "40% Chase UR -> Virgin Atlantic"), the FlightResultCard shows a label with the effective reduced cost. The bonus data is a manually-maintained static config file (`lib/transfer-bonuses.ts`) — there is no public API for transfer bonus data. Expired bonuses are automatically hidden at runtime via date comparison.

This plan runs in parallel with Plan 04-02 (same wave) because both depend only on 04-01 and modify different files. Plan 04-02 modifies `app/search/page.tsx` and creates `components/price-history-chart.tsx`. This plan modifies `lib/enrichment.ts`, `components/flight-result-card.tsx`, and creates `lib/transfer-bonuses.ts`. No overlap.

## Must-Haves (Goal-Backward)

1. `lib/transfer-bonuses.ts` defines active transfer bonuses as a typed array with `fromProgram`, `toProgram`, `bonusPct`, `description`, `expiresAt`
2. `getActiveBonuses()` filters out expired bonuses at runtime (compares `expiresAt` against today's date)
3. `getBonusesForResult()` finds all active bonuses applicable to a given airline program across all CC programs
4. `effectiveBonusCost()` computes the reduced point cost when a bonus applies (miles / (ratio * (1 + bonus/100)))
5. `EnrichedDeal` gets new optional field `transferBonuses` — array of `{ ccProgram: string; bonusPct: number; effectiveCost: number; description: string }`
6. `FlightResultCard` displays the best transfer bonus as an amber label: "40% Chase UR -> Virgin Atlantic bonus: effectively X pts"
7. Empty `ACTIVE_TRANSFER_BONUSES` array (or all expired) results in no bonus labels displayed (graceful absence)

### lib/transfer-bonuses.ts

Create a new file with the static bonus config and lookup helpers.

```typescript
/**
 * Transfer Bonus Configuration
 *
 * Manually updated when credit card programs announce transfer bonuses.
 * Bonuses are promotional offers (e.g., "40% Chase UR -> Virgin Atlantic")
 * that reduce the effective cost of points redemptions.
 *
 * There is no public API for this data — static config is the v1 approach.
 *
 * Update process:
 * 1. Check https://thepointsguy.com/loyalty-programs/current-transfer-bonuses/
 * 2. Check https://www.nerdwallet.com/travel/learn/credit-card-transfer-bonuses
 * 3. Update ACTIVE_TRANSFER_BONUSES array below
 * 4. Expired bonuses are automatically hidden at runtime (no cleanup needed)
 */

export interface TransferBonus {
  fromProgram: string;    // CC program slug, e.g. 'chase-ur'
  toProgram: string;      // Airline programCode, e.g. 'virgin-atlantic'
  bonusPct: number;       // e.g. 40 for 40% bonus
  description: string;    // e.g. '40% Chase UR -> Virgin Atlantic'
  expiresAt: string;      // 'YYYY-MM-DD' — filtered at runtime
}

// ================================================================
// ACTIVE TRANSFER BONUSES — Update when new bonuses are announced
// Expired entries are automatically hidden (no need to remove them)
// ================================================================

export const ACTIVE_TRANSFER_BONUSES: TransferBonus[] = [
  // Add active bonuses here when announced. Example format:
  // {
  //   fromProgram: 'chase-ur',
  //   toProgram: 'virgin-atlantic',
  //   bonusPct: 40,
  //   description: '40% Chase UR -> Virgin Atlantic',
  //   expiresAt: '2026-02-28',
  // },
];

/**
 * Returns only non-expired bonuses.
 */
export function getActiveBonuses(): TransferBonus[] {
  const today = new Date().toISOString().slice(0, 10);
  return ACTIVE_TRANSFER_BONUSES.filter((b) => b.expiresAt >= today);
}

/**
 * Find all active bonuses that transfer TO a specific airline program.
 * Returns bonuses from any CC program that has an active bonus to this airline.
 */
export function getBonusesForProgram(airlineProgramCode: string): TransferBonus[] {
  return getActiveBonuses().filter((b) => b.toProgram === airlineProgramCode);
}

/**
 * Compute effective points cost with bonus applied.
 *
 * A 40% bonus means 1 CC point -> 1.4 airline miles.
 * So you need FEWER CC points: effectiveCost = airlineMiles / (ratio * (1 + bonus/100))
 *
 * @param milesRequired - Airline miles needed for the award
 * @param transferRatio - Base CC -> airline ratio (e.g. 1.0 for 1:1)
 * @param bonusPct - Bonus percentage (e.g. 40 for 40%)
 * @returns Effective CC points needed (rounded up)
 */
export function effectiveBonusCost(
  milesRequired: number,
  transferRatio: number,
  bonusPct: number,
): number {
  const effectiveRatio = transferRatio * (1 + bonusPct / 100);
  return Math.ceil(milesRequired / effectiveRatio);
}
```

**Note on initial config:** The `ACTIVE_TRANSFER_BONUSES` array starts empty with a commented example. As of late February 2026, the Chase UR -> Virgin Atlantic 40% bonus and Capital One -> JAL 30% bonus may have expired (expiry was Feb 28). Rather than include potentially-expired bonuses, the array starts empty. The maintainer should check current bonuses and populate when deploying.
